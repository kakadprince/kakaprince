# Membership Portal Prototype

This repository contains a prototype membership portal with an integrated LMS/eLearning experience for a professional institute. It includes a frontend UI mock, backend API structure, and database schema plus sample data.

## Structure

- `frontend/` – React-based (CDN) responsive UI prototype.
- `backend/` – Node.js/Express REST API skeleton with dummy data.
- `database/` – SQL schema and sample seed data.

## Quick Start (Prototype)

### Frontend

Open `frontend/index.html` in a browser. The UI is built with React via CDN and is purely client-side for demonstration.

### Backend

```bash
cd backend
npm install
npm run dev
```

The API starts on `http://localhost:4000`.

## Notes

- Authentication and payment gateway integrations are placeholders.
- AI-powered features are stubbed to show intended integration points.
- This is a starting point for a full product implementation.
